## 🏗️ Infrastructure Stack
- **Cloud Provider**: AWS (VPC, EKS, ALB, Route53, CloudWatch)
- **IaC**: Terraform (Modular & State-managed)
- **Orchestration**: Amazon EKS (v1.30) with Managed Node Groups (`t3.micro`)
- **Networking**: Multi-AZ Private/Public Subnets with NAT Gateway isolation.

## 🔄 CI/CD & DevSecOps
- **CI/CD Tool**: Jenkins (Declarative Pipeline)
- **Security**: SonarQube Static Analysis & Quality Gates
- **Artifacts**: Nexus Repository Manager
- **Deployment**: Helm Charts & Kubectl
